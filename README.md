# Logoxels

Android vector logo designer by Pixels Limited. Native Kotlin + Jetpack Compose, offline, no account.

Stages: 1 engine, shapes, pathfinder, align, style (done) · 2 pen tool, knife/scissors, groups/layers, clipping · 3 grids/snapping/guides, gradients, rotation · 4 text (outlines, on path, in shape, warp, wrap), image trace, icon library · 5 export SVG/PNG/PDF, project files.

Build: push to `main`; GitHub Actions builds the APK and attaches it to a release.
