# Logoxels

Android vector logo designer by Pixels Limited. Native Kotlin + Jetpack Compose, offline, no account.

Stages: 1 engine, shapes, pathfinder, align, style (done) · 2 true corner rounding on any shape, per-corner radius (done) · 3 pen tool, knife, groups, layers panel, clip to shape (done) · 4 node editing + scissors, grids/snapping/guides, gradients, rotation · 5 text (outlines, on path, in shape, warp, wrap), image trace, icon library · 6 export SVG/PNG/PDF, project files.

Build: push to `main`; GitHub Actions builds the APK and attaches it to a release.
