# Logoxels

Android vector logo designer by Pixels Limited. Native Kotlin + Jetpack Compose, offline, no account.

Stages: 1 engine, shapes, pathfinder, align, style (done) · 2 true corner rounding on any shape, per-corner radius (done) · 3 pen tool, knife, groups, layers panel, clip to shape (done) · 4 node editing + scissors, grids/snapping/guides/rulers, gradients, rotate/flip (done) · 5 live text (fonts, on path, in shape, flow around objects, warp, to outlines), image trace, shape library (done) · 6 export SVG/PNG/PDF/PSD/EPS/AI and project files (done early).

Build: push to `main`; GitHub Actions builds the APK and attaches it to a release.
